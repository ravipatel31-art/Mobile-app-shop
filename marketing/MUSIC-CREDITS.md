# Music credit — demo videos

`marketing/music.m4a` is **Gymnopédie No. 1** by Erik Satie, performed by
Kevin MacLeod — trimmed to 58.6 s and mastered to a quiet background level by
`tools/build_demo_video.sh`.

- **Source:** <https://commons.wikimedia.org/wiki/File:Kevin_MacLeod_-_Erik_Satie_Gymnopedie_No_1.ogg>
- **License:** CC BY 3.0 — free to use, including commercially, with credit.

## Where to put the credit

CC BY requires attribution "to the extent reasonably practicable". Paste this
line wherever you post the video (description / caption):

> Music: "Gymnopédie No. 1" — Erik Satie, performed by Kevin MacLeod
> (incompetech.com). Licensed under CC BY 3.0.

- **YouTube:** description box (required if you ever run it as an ad).
- **Instagram Reels / WhatsApp status:** one line at the end of the caption.
- **Landing page:** fine as-is — keep this file in the repo as the record.

## Swapping the track

Drop any ~60 s audio file at `marketing/music.m4a` and re-run
`tools/build_demo_video.sh`. If the new track needs credit, update this file.
