# Cafe POS — 60-second demo video (Ken Burns slideshow)

This is your #1 sales asset. It's built from the **generated app screenshots** —
no screen recording, no camera, no video skills.

**It's already rendered for you:**

| File | Aspect | Where it plays |
|------|--------|----------------|
| `marketing/demo-60s.mp4` | 1080×1920 (9:16) | WhatsApp status, Instagram Reels, in-person demos |
| `docs/demo.mp4` | 1920×1080 (16:9) | Landing page `#video` section, YouTube |

Rebuild both (or just one) after any UI change:

```bash
tools/build_demo_video.sh          # both
tools/build_demo_video.sh 9x16     # vertical only
```

Needs `ffmpeg` + ImageMagick; the screenshots come from the goldens (§0).
Text overlays (Fraunces + Inter, gold keywords) are burned in, and
`marketing/music.m4a` (Satie's *Gymnopédie No. 1* by Kevin MacLeod, CC BY) is
mixed in as the background bed — **post the credit line from
[`MUSIC-CREDITS.md`](MUSIC-CREDITS.md) with the video.** Swap or remove the
track by replacing/deleting that file and re-rendering. Canva is now optional,
only if you want to restyle anything.

**The one rule:** show the real app. No slides, no stock footage. The polish
you built (dark + gold UI) *is* the pitch.

## 2. Canva assembly (≈45 min)

1. **New design →** *Mobile Video* (1080×1920). *(For a YouTube/website version, also
   make a 1920×1080 Landscape copy.)*
2. **Upload** the 8 screenshots (from `mobile/test/goldens/`) + a logo PNG if you have one.
3. **Drop images on the timeline** in the order above. Set each to the beat length
   from the table (Canva: click the clip → set duration).
4. **Ken Burns motion:** select a clip → **Animate → Pan** (or *Zoom*). Pick the
   direction in the table. Keep the speed **slow** — this is the whole reason the
   stills feel like video.
5. **Text overlays:** add each line from the table. Settings:
   - Font: **Fraunces** (headings) + **Inter** (captions) — same as your app/site.
   - Colour: **Gold `#E6B25A`** on the keywords, white for the rest.
   - Place **centre-low third** so it never covers the part of the screen you're
     zooming into.
6. **Transitions:** *Dissolve*, 0.2s — between every clip. Nothing fancy.
7. **Music:** Canva audio → search *"upbeat corporate"* / *"lofi chill"*, **low volume**
   (you should still read the captions).
8. **Captions:** add them as text (don't rely on auto-captions) — most people watch muted.
9. **CTA card (last 3s):** big gold **"Book a free demo"** + your phone number + WhatsApp.

### Make it feel premium (3 tiny tricks)
- **Vary the motion** — alternate zoom-in / pan-up / pan-down so no two consecutive
  scenes feel identical.
- Add a **1px gold outline** to the phone screenshots (Canva: Elements → Frame, or
  Border) — reads as "product," not "photo of a screen."
- Start and end on the **dashboard** (`login` → `hero`) — it bookends the story.

## 3. Export specs

- **Format:** MP4 (H.264) + AAC audio
- **Aspect:** 9:16 (1080×1920) for Reels/Shorts/in-feed · 16:9 (1920×1080) for YouTube
- **Length:** 60s works for **skippable in-stream** and **in-feed**
- **File size:** keep under 1 GB (Canva easily)
- **First 5 seconds must hook** — that's all most people see before skipping

> Canva: **Share → Download → MP4 Video**, highest quality.
